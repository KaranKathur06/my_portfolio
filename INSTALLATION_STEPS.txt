🎉 YOUR PORTFOLIO IS READY!

Follow these simple steps to get started:

───────────────────────────────────────────────────────────────────
STEP 1: INSTALL DEPENDENCIES
───────────────────────────────────────────────────────────────────

Open your terminal in this directory and run:

    npm install

This will install all required packages (~150MB).
Wait for it to complete (2-3 minutes).

───────────────────────────────────────────────────────────────────
STEP 2: CREATE ENVIRONMENT FILE
───────────────────────────────────────────────────────────────────

Create a new file named:  .env.local

Add this content:

    NEXT_PUBLIC_GITHUB_USERNAME=KaranKathur06

Optional (but recommended for higher API limits):

    NEXT_PUBLIC_GITHUB_TOKEN=your_github_token_here

To get a GitHub token:
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Name it: "Portfolio Website"
4. Select scope: "public_repo"
5. Generate and copy the token
6. Paste it in .env.local

───────────────────────────────────────────────────────────────────
STEP 3: START DEVELOPMENT SERVER
───────────────────────────────────────────────────────────────────

Run:

    npm run dev

Then open your browser to:

    http://localhost:3000

You should see your portfolio! 🎊

───────────────────────────────────────────────────────────────────
STEP 4: CUSTOMIZE YOUR CONTENT
───────────────────────────────────────────────────────────────────

Update these files with your information:

1. Contact Info:
   - File: components/Contact.tsx
   - Update: email, phone, location

2. Social Links:
   - File: components/Footer.tsx
   - File: components/Contact.tsx
   - Update: GitHub, LinkedIn, Twitter URLs

3. About Section:
   - File: components/About.tsx
   - Customize your bio

4. Skills:
   - File: components/Skills.tsx
   - Adjust skill levels

See CUSTOMIZATION.md for detailed instructions.

───────────────────────────────────────────────────────────────────
STEP 5: DEPLOY (OPTIONAL)
───────────────────────────────────────────────────────────────────

Deploy to Vercel (recommended):

1. Push to GitHub:
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin YOUR_GITHUB_REPO_URL
   git push -u origin main

2. Go to: https://vercel.com
3. Import your repository
4. Add environment variables
5. Deploy!

See DEPLOYMENT.md for other platforms.

───────────────────────────────────────────────────────────────────
VERIFY YOUR SETUP
───────────────────────────────────────────────────────────────────

───────────────────────────────────────────────────────────────────
TROUBLESHOOTING
───────────────────────────────────────────────────────────────────

Port already in use?
    npm run dev -- -p 3001

GitHub API not working?
    - Check .env.local exists
    - Verify NEXT_PUBLIC_GITHUB_USERNAME is set
    - Add NEXT_PUBLIC_GITHUB_TOKEN for higher limits

Build errors?
    rm -rf .next node_modules
    npm install
    npm run build
